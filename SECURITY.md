# Security

Report a vulnerability to admin@switon.dev. Do not open a public issue.

Include the PHP version, the NTS or ZTS build, the platform, and the smallest input that shows the problem. A crash, a wrong score, or a string that should have been rejected all count.

The supported PHP versions are 8.2 to 8.5, which is the range in `composer.json`. A fix ships as a patch release, and its notes name the affected versions.
